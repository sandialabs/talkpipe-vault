Folders — where their indexes are kept

Kept in the folder, an index travels with it and is shared by every vault process that opens it. Folders that are read-only, on a network share, or synced by a cloud client always keep theirs in the app's data directory. Folders already indexed keep their index where it is.

Agent retrieval — Search and Ask page option

With "Let an agent select the results" checked on the Search page, or "Use Agent" on the Ask page, the agent searches until it judges that the chunks it has kept would answer the question well — however many that turns out to be. On Ask, those chunks are the context the answer is built from. The two limits below only bound a run that never reaches that judgement; they are not targets to fill.

The agent runs on the chat model above, which must support tool calling. A model that is weak at it tends to end a run without keeping what it found — the result note then says it "stopped without saying it had enough" — so if that keeps happening, try a stronger tool-calling model.

The most chunks one run may keep. Reaching it stops the run, so raise it if answers look like they were cut off mid-gathering, and lower it to keep the context (and the cost of an answer) small.

Maximum number of reasoning turns the agent may take per search or question before it is stopped, whether or not it has decided it has enough.
